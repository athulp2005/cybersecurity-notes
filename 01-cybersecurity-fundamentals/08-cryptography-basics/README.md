# Cryptography Basics

## 📖 Overview

Cryptography is the practice of protecting information by converting readable data into an unreadable format. It ensures that sensitive information remains secure during storage and transmission, allowing only authorized users to access the original data.

Cryptography is one of the core technologies used in modern cybersecurity.

## 🔐 What is Cryptography?

Cryptography is the science of securing information using mathematical techniques.

Its primary goal is to protect data from unauthorized access while ensuring secure communication between users.

---

## 🎯 Objectives of Cryptography

Cryptography helps to:

- Protect sensitive information
- Secure online communication
- Prevent unauthorized access
- Maintain data confidentiality
- Verify data authenticity

---

## 🔄 Encryption and Decryption

### Encryption

Encryption converts readable information (plaintext) into an unreadable format called ciphertext using an encryption algorithm and a key.

**Example**

```
Plaintext → Encryption → Ciphertext
```

---

### Decryption

Decryption converts ciphertext back into the original plaintext using the appropriate key.

**Example**

```
Ciphertext → Decryption → Plaintext
```

## 💡 Key Points

- Cryptography protects information from unauthorized access.
- Encryption converts plaintext into ciphertext.
- Decryption converts ciphertext back into plaintext.
- Cryptography is widely used in modern digital services.
- Strong cryptography is an essential part of cybersecurity.

## 📌 Summary

Cryptography is a fundamental cybersecurity concept used to protect sensitive information. By encrypting data and allowing only authorized users to decrypt it, cryptography helps maintain secure communication, protect privacy, and secure digital systems.
