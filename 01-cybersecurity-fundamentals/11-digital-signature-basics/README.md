# Digital Signature Basics

## 📖 Overview

A Digital Signature is a cryptographic technique used to verify the authenticity, integrity, and origin of digital information. It helps ensure that a document or message has not been modified and confirms the identity of the sender.

Digital signatures are widely used in secure communication, online transactions, software distribution, and electronic document signing.

## ✍️ What is a Digital Signature?

A Digital Signature is a cryptographic mechanism that allows a sender to digitally sign data so that the receiver can verify:

- The identity of the sender.
- That the data has not been modified.
- That the sender cannot deny sending the data.

Unlike a handwritten signature, a digital signature is created using cryptographic algorithms.

---

## 🔑 Why are Digital Signatures Important?

Digital signatures help to:

- Verify the identity of the sender.
- Protect data from modification.
- Build trust in digital communication.
- Secure electronic transactions.

---

## ⚙️ How Digital Signatures Work (Basic Concept)

1. A sender prepares a document or message.
2. A hash of the document is generated.
3. The hash is digitally signed using the sender's private key.
4. The signed document is sent to the receiver.
5. The receiver verifies the signature using the sender's public key.
6. If verification succeeds, the document is considered authentic and unchanged.
